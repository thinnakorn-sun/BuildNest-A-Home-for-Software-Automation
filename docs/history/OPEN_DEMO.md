# Open the BuildNest M1.1 demo

## Quickest way
Open `BuildNest_M1_1_DesignLocked_Demo.html` (provided separately from this ZIP) in a browser. This is a self-contained, browser-only prototype. There are no installers and no real payment integrations.

## From ZIP
Open `apps/web/public/buildnest/index.html` on a personal computer. Keep `styles.css`, `enhancements.css` and `app.js` next to it.

## What to try
1. Marketplace → product details → simulated checkout → My Library → Read guide.
2. Automations → set number of sample records → Run → Export sample JSON.
3. Free tools → upload local CSV (under 2 MB) → Validate → Export JSON report.
4. Admin dashboard → Add/Edit demo product → Export catalog.
5. Toggle language and dark mode and try mobile navigation.

## Safety notice
This prototype uses browser-local storage; no real authorization, paid transactions, SaaS billing, Apify Runs or file licenses. It is not a production backend.
